# Skills dos Agentes

As skills são capacidades operacionais reutilizáveis. Um agente deve consultar este índice e os arquivos individuais antes de atuar.

| Skill | Finalidade |
| --- | --- |
| [frontend-react](./frontend-react.md) | Implementar páginas, componentes e interações React com os padrões do projeto. |
| [fullstack-express](./fullstack-express.md) | Evoluir o servidor Express e contratos compartilhados com segurança. |
| [quality-validation](./quality-validation.md) | Planejar e executar validações técnicas, funcionais e de acessibilidade. |
| [project-governance](./project-governance.md) | Operar com planos, documentação, critérios de aceite e rastreabilidade. |

## Regra de uso

Skills não substituem os documentos de arquitetura nem autorização de escopo. Elas devem ser aplicadas em conjunto com `/agents.md`, o plano da tarefa e as diretrizes em `/docs/`.
