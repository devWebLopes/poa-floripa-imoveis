# Skill: Frontend React

## Capacidade

Construir e modificar interfaces React 19 em TypeScript, usando Vite, Wouter, Tailwind CSS 4, Radix UI, componentes shadcn-style e Lucide.

## Regras

- Inspecionar componentes existentes antes de criar novos.
- Usar `@/` para imports do cliente e manter componentes de UI genéricos em `components/ui/`.
- Preservar responsividade, semântica, acessibilidade e identidade visual.
- Isolar estado local; elevar estado somente quando houver necessidade real de compartilhamento.
- Não colocar segredos ou regras de servidor em código do cliente.

## Entregáveis

- JSX/TSX tipado;
- estados de loading, vazio, erro e sucesso quando aplicável;
- comportamento de teclado e foco;
- validação com `pnpm check` e `pnpm build`.
