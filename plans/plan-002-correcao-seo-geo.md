# Plano 002 — Correção de SEO e GEO

## Metadados

- **Tarefa:** corrigir os apontamentos do relatório de SEO e GEO da Poa Floripa Imóveis.
- **Agente principal:** Frontend Engineer
- **Agentes de apoio:** Backend Engineer e QA Engineer
- **Skills:** `frontend-react`, `fullstack-express`, `quality-validation`, `project-governance`
- **Status:** concluído

## Escopo

- reforçar metadados, canonical, Open Graph, Twitter Cards e favicon;
- adicionar JSON-LD de Organization, WebSite, WebPage, RealEstateAgent e FAQPage;
- disponibilizar `robots.txt`, `sitemap.xml` e `llms.txt`;
- tornar conteúdo essencial visível no HTML inicial por meio de `noscript`;
- criar uma área editorial `/blog` com conteúdo institucional e URLs rastreáveis;
- adicionar FAQ e listas semânticas na página inicial;
- traduzir a página 404 para português do Brasil.

## Critérios de aceite

- [x] build e verificação TypeScript concluídos;
- [x] recursos técnicos são copiados para `dist/public`;
- [x] homepage e `/blog` possuem conteúdo rastreável, headings e links válidos;
- [x] schemas JSON-LD são válidos sintaticamente e não inventam perfis sociais;
- [x] `robots.txt`, `sitemap.xml` e `llms.txt` estão acessíveis como arquivos estáticos;
- [x] página 404 mantém linguagem e marca em português.

## Limitações

- O relatório não fornece perfis sociais oficiais para `sameAs`.
- O domínio canônico adotado é o domínio avaliado no relatório: `poafloripa-vvafuyxn.manus.space`.
